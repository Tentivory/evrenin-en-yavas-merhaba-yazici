# Evrenin En Yavaş Merhaba Yazıcısı

Bu proje, insanlığın en büyük sorunu olan "Merhaba Dünya" yazma işleminin çok hızlı olmasından kaynaklanan varoluşsal kaygıyı çözmek için yaratılmıştır.

## Nedir Bu?

`merhaba.py` adlı script, "Merhaba Dünya!" kelimesini harf harf, her harf arasında tam 10 saniye bekleyerek yazar. Neden? Çünkü hız kötüdür. Sabır erdemdir. Ve biz erdemli insanlarız.

## Nasıl Çalıştırılır?

```bash
python merhaba.py
```

Çalıştırdığınızda hayatınızın anlamını sorgulamaya başlayacaksınız. Tavsiye edilir.

## Özellikler

- Tamamen çalışan kod (gerçekten)
- Sonsuz bekleyiş hissi
- Hiçbir şey yapmama sanatı
- Evrenin ısısını düşürme potansiyeli (kanıtlanmadı)

## Uyarı

Bu programı çalıştırdıktan sonra bilgisayarınızın zaman algısı bozulabilir. Sorumluluk kabul etmiyoruz.
